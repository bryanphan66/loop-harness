Đang ùn ở đâu

Thanh dài = nhiều issue đang đứng ở state đó. Số bên phải là tuổi của issue nằm lâu nhất — một state ít việc nhưng tuổi cao thì đáng lo hơn một state đông mà chảy nhanh. Thanh tím = có issue đứng ≥ 7 ngày ở một state lẽ ra phải chảy; Backlog không bao giờ tính là ùn vì nằm chờ đúng là việc của nó.

Worker đang chạy

Trang này đọc run-log.jsonl (sinh bởi scripts/run-log.mjs) và board.json (ảnh chụp bảng issue) đặt cạnh nó. Thiếu file nào thì phần đó rơi về dữ liệu mẫu và banner ở trên đổi màu để nói rõ.
Đổ dữ liệu thật: node scripts/run-log.mjs start --issue N … lúc giao việc, … end --run <id> --outcome done lúc xong. Sau ~20–30 vòng thì bảng so bản harness mới có nghĩa.
